# Historical Flutter validation sources

These files preserve the former Flutter client's widget tests, scripted
multiplayer checks, screenshot comparison logic and documentation. They
are historical evidence, not executable native tests or launch instructions.
The Flutter application and its build toolchain have been retired.

The active native suite is `../native-integration.sh` and the Swift package
tests in `../../apple/Tests/`. Dart simulation/server tests remain unchanged
in `../../core/test/` and `../../server/test/`.

No historical screenshot, widget or browser result is a claim about the
native app. Layout/input/visual parity need separate native UI validation.
