# Historical Flutter evidence

This directory archives the previous client’s documentation and four-platform
recording/visual-comparison harness. It is **not an active build or test path**.
The old client has been removed. The archived launcher has a `.txt` extension
to prevent accidental execution. The archived scripts depend on retired app
paths and Flutter viewport reports and are kept only to interpret old evidence.

Use `../../README.md` for native Apple commands. The active
`../multiplayer-e2e.sh` exercises Swift Codable models, the actual
`URLSessionWebSocketTask` transport, and the existing Dart backend. Its complete
four-client Opera Game assertions retain the old harness’s expected FEN/SAN and
checkmate outcome. The Dart core and server test suites remain unchanged.

Native view rendering, interaction geometry and visual parity require a
separate approved UI testing run. Passing protocol tests makes no claim about
those.
