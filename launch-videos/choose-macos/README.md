# Launch video: Choose macOS

30s, 1920x1080 @ 60fps Remotion film. The environment picker's macOS chip morphs into Devin's cloud Mac, the Simulator boots, Devin plays the Otter game with computer use, and the test recording shows 6 passed checks.

```sh
npm install
DV1=/path/to/dv1.mp4 npm run footage   # extracts real Computer-pane footage (not committed)
npm run render                          # out/choose-macos.mp4
npm run poster                          # out/poster.png
```

UI values and icons come from the Figma file `vPLOWDwez4ZK6iQnPTCnN5` (Devin Screenshots).
